# AI Overnight

A friendly crash course on how modern AI works: short lessons, quizzes with trick questions, and a prompt you can paste into your own AI to get a tutor. No AI runs on this page and nothing leaves your browser.

The full course: seven lessons, nine quizzes (two are reviews), a concept map, an anatomy of AI, a mock interview and a study prompt builder. Scores stay in your browser. Sounds are generated in the browser with the Web Audio API and can be switched off.
