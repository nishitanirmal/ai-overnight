# AI Overnight

A friendly crash course on how modern AI works: short lessons, quizzes with trick questions, and a prompt you can paste into your own AI to get a tutor. No AI runs on this page and nothing leaves your browser.

This is a preview of the redesign: Home, Lesson 2 (How LLMs work), its quiz and the Delight kit of loaders. Sounds are generated in the browser with the Web Audio API and can be switched off.

- Icons: [Phosphor Icons](https://phosphoricons.com) (MIT license), duotone style
- Mascot: Toki, original to this project
